# Yummy - Recipe Discovery & Cooking App

**Mobile Application Development Project**  
**2nd Year • Semester 2 • 2025/2026**  
Developed by: Monali Watareka

Yummy is a simple, beautiful Android application that helps users discover, explore and save delicious recipes. The app focuses on an easy-to-use interface with category-based browsing, recipe details, profile management, notifications, and community feel — perfect for everyday cooking inspiration.


## ✨ Features

- Beautiful splash screen + animated start screen
- Login / Get Started flow
- Home screen with food categories (Seafood, Meat, etc.)
- Recipe list by category (example: Butter Chicken, ...)
- Detailed recipe view with image, ingredients & instructions placeholder
- Profile screen — view/edit name, bio, gender, links
- Edit Profile page
- Save / Bookmark recipes screen (placeholder)
- Notifications screen (placeholder)
- Community page (placeholder title)
- Bottom navigation bar (Home, Add, Bookmark/Collection, Profile)
- Back navigation & share buttons in most screens
- Consistent green-themed Material Design look

## 🛠️ Technologies Used

- **Language**: Kotlin
- **IDE**: Android Studio
- **UI**: View Binding + XML layouts
- **Layout**: ConstraintLayout + CardView + Material Components
- **Navigation**: Intents between activities (no Navigation Component yet)
- **Theme**: Material3 DayNight NoActionBar + custom green colors
- **Storage**: None (static UI – can be extended with Room / SharedPreferences)
- **Minimum SDK**: 21 (Android 5.0+)
